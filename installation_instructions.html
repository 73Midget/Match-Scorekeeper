Match Scorekeeper — How to Install

Scoring app for GSSF-style indoor & outdoor matches

Open this address on your devicegpl-scorekeeper.netlify.app
You don't download anything from an app store. You open the address above in your web browser once, then add it to your home screen. After that it behaves like a normal app — it has its own icon and works with no internet at all, which is what we need at the range.

Install it

iPad or iPhone Safari only

  1. Open Safari and go to the address above.
    This must be Safari. Chrome on an iPad can't install apps.
  2. Tap the Share button — the square with an arrow pointing up.
  3. Scroll down the list and tap Add to Home Screen.
  4. Tap Add in the top right.
  5. Close Safari, then tap the new bullseye icon on your home screen.
  6. While you still have internet, let it finish loading once.

Android tablet or phone Chrome

  1. Open Chrome and go to the address above.
  2. Tap Install if it offers, or tap the ⋮ menu and choose Install app (sometimes called Add to Home screen).
  3. Confirm Install. The icon appears on your home screen.
  4. Open it from the icon and, while you still have internet, let it finish loading once.

Windows PC or Mac laptop

Either way works — pick whichever you prefer:

  • Simplest: just open the address and bookmark it. Nothing else to do.
  • As an app window: in Edge or Chrome, click the install icon in the address bar (or menu → Apps → Install). On a Mac in Safari, use File → Add to Dock.

Firefox can't install it as an app, but the website works normally — just bookmark it.

Needs internet the first time only. After that first load it opens and works completely offline. You can score an entire match with no signal.

Important — for tablets used at matches

Always open it from the home screen icon, never from Safari or Chrome.
The icon version and the browser version keep separate saved data. If you score a squad in the browser by mistake, those scores won't be in the app. On iPads there's a second reason: the browser version can quietly discard its saved data after about a week of not being used, while the home screen version does not.
Never use "Clear History" or "Clear browsing data" on a match tablet. On an iPad, clearing Safari's history can also wipe the app's saved scores.

Updates

Updates install themselves. There's nothing to download and no app store to check.

  1. Fully close the app — don't just switch away from it. On a tablet, swipe it away from the recent-apps list.
  2. Open it again while you have internet. The new version loads.
  3. To confirm, look at the Match Setup screen — it shows the version and build number. Every tablet at a match should show the same one.
Updates never install in the middle of a match. If a new version comes out while you're scoring, it waits until the next time the app is fully closed and reopened.

If something's not right

ProblemWhat to do
App won't open with no internet It needs one successful online load first. Get on wifi, open it once, let it finish loading.
Tablet shows an older version than everyone else Fully close it and reopen while online. Check Match Setup again.
No "Add to Home Screen" on an iPad You're probably in Chrome. Open the address in Safari instead.
iPad: tapping a name or email box brings up no keyboard This is an Apple bug affecting installed web apps generally, not this app. Restarting the iPad usually fixes it. Scoring is unaffected.
My scores disappeared Check whether you opened it in the browser instead of from the home screen icon — those keep separate data. Tell the match director; a backup can usually be restored.
Two identical icons? If the address ever changes, delete the old icon once your data has been moved across. Two look-alike icons on the same tablet is how a squad's scores end up in the wrong place.
