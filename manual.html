Match Scorekeeper

User manual — scoring for GSSF-style indoor & outdoor matches

app v2.0.0

This app keeps score for a squad on one tablet, with no internet needed. Each tablet holds its own squad; at the end of the match the squads are combined on one device to produce the final results. A club can optionally connect the tablets to a server, which makes sharing the shooter list and collecting squad results easier — but nothing requires it.

1 · How It Works

  • One tablet = one squad. Each RO scores their own squad on their own device.
  • Everything saves as you go. Look for the ✓ saved time at the top right. Locking the screen or closing the app doesn't lose anything.
  • Indoor or outdoor. The match type is chosen at the start and stays fixed for that match.
  • Squads combine at the end. One person collects every squad and compiles the results.
  • Online is optional. Without a server, the app makes no network calls at all and every feature described here still works — squads are passed between tablets as files. With a server, squads upload and the results compile automatically.
The shooter list is kept between matches. Starting a new match clears the scores and check-ins but keeps everyone's names, emails and details on file, ready for next time.

2 · Installing

There's no app store download. Open the address below once in a browser, then add it to the home screen. After that it has its own icon and works completely offline.

gpl-scorekeeper.netlify.app

iPad or iPhone

  1. Open the address in Safari — this must be Safari.
  2. Tap Share, scroll down, tap Add to Home Screen, then Add.
  3. Close Safari and open the new bullseye icon.
  4. While you still have internet, let it finish loading once.

Android

  1. Open the address in Chrome.
  2. Tap Install, or menu ⋮ → Install app.
  3. Open it from the new icon and let it finish loading once while online.

Windows or Mac

  • Open the address and bookmark it, or install it as an app window from the address bar.
  • On a Mac in Safari, use File → Add to Dock.
Always open it from the home screen icon, never from the browser. The icon version and the browser version keep separate saved data. On iPads there's a second reason: the browser version can quietly discard its data after about a week unused.

For the same reason, never use "Clear History" on a match tablet.

3 · Updating

Updates install themselves. Fully close the app — swipe it off the recent-apps list — then open it again while you have internet. Check Tools: it shows the version and build, and every tablet at a match should show the same one.

Updates never install mid-match. A new version waits until the app is fully closed and reopened.

4 · The Tools Screen

The Tools button at the top right opens the Tools screen, which holds everything that isn't scoring. It's available from every screen, including before a match has started.

GroupWhat's in it
This Tablet Squad name, device name, screen mode, version and build. Set once and rarely changed.
Shooter List View and edit the list, and download the club's current one.
This Match Match date, compile results, restore a squad, save a file.
Connection Online services on or off, and the club's setup code.
Careful Undo, restore from a backup, start a new match. The three that change or remove data.
Squad and device name are locked. They're shown but not directly editable — tap Change squad / device name and confirm. The squad name labels every file and upload this tablet produces, so it shouldn't change on a stray keystroke.

5 · Match Setup

Match Setup is the first screen you see. It defines the match before any scoring begins.

  1. Match type — Outdoor or Indoor.
  2. Match date — pick it from the calendar. Every tablet must have the same date; it's how the app knows which squads belong together.
  3. Check in shooters — see section 6.
  4. Tap › Start match.
The match type locks when you tap Start match. Indoor and outdoor score completely differently, so changing it means starting a new match.
The squad name is shown on Setup but changed in Tools, and so is the match date once the match is under way.

6 · Shooters & Check-In

Tap Check in shooters and pick a name to open their card. Set their division and Glock model for tonight, their email, and the RO tick if their address should always be included in the results email.

Use + Add shooter for someone not on the list. Latecomers can be checked in at any point.

Shooting order is check-in order — the roster is numbered in the order people were checked in.
Rimfire and the G44. Rimfire is shot with a G44, so picking one offers to set the other. If a shooter ends up with a mismatched pair — from an import, or an edit made elsewhere — a check division/gun badge appears next to them on the roster and score screen. It doesn't block anything; it's a reminder.

Shooting more than one division

A shooter can enter more than one division in the same match, each with its own Glock. Each entry is scored and ranked separately, but they still appear as one person in the check-in list. On an outdoor score sheet, use + Add another division.

7 · Scoring — Outdoor

From the Roster, tap a shooter to open their score sheet.

Entering times

Tap a String box and the number pad appears. Type the digits and the decimal fills in from the right — 1673 becomes 16.73. On a laptop you can type on the keyboard, press Enter to save or Esc to cancel.

Entering hits

  • Tap a zone box (A, C, D, miss) to add one hit.
  • Long-press to reset it to zero.
  • Taps past the limit for that target are refused.

Confirming a stage

Tap ✓ Confirm stage, check the total, and Accept. The stage locks — green banner, greyed inputs — until you tap Review / edit then Unlock & edit.

Everything has to add up before a stage will confirm.
  • Paper targets: A + C + D + misses must equal 6 on every target (3 for Major Sub and Pocket Glock).
  • Glock'M steel: hits plus poppers left standing must total 3 — one per string.
  • Glock the Plates: hits plus plates left standing must total 6 on every string.
The app names the target or string that's short. This catches the mistake that matters — a target or popper left unrecorded, which silently drops a penalty.

8 · Scoring — Indoor

Indoor matches are scored by score and X count, not by time. Tap a shooter to open their rounds.

Each round records a score (0–500) and an X count (0–50). Tap either box to open the number pad. Tap ✓ Confirm round and Lock when it's done.

Shooting more rounds

A shooter fires at least one round and may shoot more, each with a different Glock and division. Finish and confirm the current round, then tap + Add another round — it stays greyed out until the current one is confirmed. Before a round is locked you can also tap change to correct its gun or division.

Every round is ranked on its own. A shooter who fires three rounds appears three times in the results, and the results also show a per-shooter summary and their best round.

9 · DNF & DQ

On the score sheet, set Status to DNF or DQ. Tap again to clear it. Outdoor applies it to the shooter's entry; indoor applies it to that round, so a shooter can complete one round and DNF another. Both are listed at the bottom of the results rather than given a place.

10 · Reading Results

The Results tab ranks everyone, with filter chips for division and squad.

Outdoor

Lowest total wins. Each row shows the shooter, division, Glock and match total. Identical totals share a place — two shooters tied for first are both shown as first, and the next shooter is third.

Indoor

Highest score wins; X count breaks ties. Identical score and X share a place. Results also include best per division and a per-shooter summary listing all their rounds.

Under the buttons you'll see when this squad was last saved, uploaded, and — on the compiling tablet — how many squads the results were compiled from.

11 · Finishing Your Squad

When your squad is done, tap the button at the top of Results:

ButtonWhat it does
Upload this squad's results
(online)		 Saves a file to this tablet and uploads it to the club server.
Save this squad's results
(offline)		 Saves a file to this tablet. Hand it to whoever is compiling.
It always saves locally first. If the upload fails, the file is still on the tablet and a yellow badge appears at the top of the screen. Tap the badge to try again once you have signal.

The other buttons on Results are for producing and sending the finished results — the PDF, the email list, and the CSV — and for compiling the match if you're the one doing that.

12 · Online Services

Optional. A club can run a small server so tablets can share the shooter list and collect squad results without passing files around. The app works fully offline without it, and with no server configured it makes no network calls at all.

Setting a tablet up

  1. Tools › Connection, tick Enable online services.
  2. Paste the club's setup code and tap Check & save.
  3. The app checks it against the server and shows the club's name, so you can confirm you were given the right one.
Treat the setup code like a password. It lets any tablet upload to your club. Don't email it around or leave it on screen. You can scan it from a QR code with the tablet's camera app and paste it in.
Unticking Enable online services keeps the setup code — it's a temporary offline switch, not a wipe. Replace setup code is how you change clubs or fix a bad code.

What it gives you

  • Get the shooter list before a match instead of restoring a file on every tablet.
  • Upload each squad at the end, so the compiler doesn't have to collect files.
  • Recover a dead tablet — its last upload is on the server.
  • Publish automatically when the match is compiled.
  • Look up past matches — see below.

Past matches

Tools › Past matches on the server lists the club's earlier matches with their date, type and how many squads they had. Pick one to read its final results, and save a PDF if you need one.

Viewing a past match doesn't touch the match on this tablet — you can look one up part-way through a live match safely. Matches that were never compiled are shown but can't be opened, since there are no final results to read.

13 · The Shooter List

Tools › View & edit shooter list shows everyone on this tablet, one row per person, with search. From here you can add a shooter, remove one, and publish the list to the club.

Removing someone

Removing takes out that person and all of their entries, so a shooter with several divisions doesn't leave orphans behind. If they have scores in this match, you're warned first. Undo in Tools reverses it.

Publishing

Publishing makes this tablet's list the club's list. Every tablet that downloads it afterwards gets this one.

Only publish from a tablet that has the full picture. That means either the match director curating the list before a match, or the tablet that has just compiled the match. A squad tablet part-way through a match only has its own view, and publishing from it would drop shooters other squads added — so the app warns you if you try.
You don't normally need to publish by hand at all. Compiling the match publishes for you (section 14), which is how walk-ins added during a match reach the club list.

Earlier versions

Earlier versions lists every published list with who published it, how many shooters it had, and when. If a bad list was published, pick an earlier one and roll back — the old list is loaded and published again as a new version. Nothing is deleted, and the history records that a rollback happened.

The shooter count is usually the giveaway: 44, then 41, then 44 makes a mistaken publish obvious at a glance.

14 · Compiling the Match

One person collects every squad and produces the final results. Tap Compile match results on the Results screen, or in Tools › This Match if this tablet hasn't scored a squad itself.

The compile screen lists every squad uploaded for this match. Tick the ones to include and tap Compile selected squads. If a squad sent a file instead of uploading, use + Add squad files — file and server squads compile together in one operation.

What the screen tells you

You'll seeWhat it means
already compiled That squad is in these results and is unticked by default. Leaving it unticked protects any corrections you've made since.
2 tablets Two tablets used the same squad name. Either two squads were labelled the same — compile both — or a replacement tablet took over, in which case compile one. Tap Show shooters on each: overlapping names mean a replacement.
new tablet That device's first upload for this club. Usually a borrowed tablet.
Upload times Shown as 7:42 PM (1h ago). An outlier is worth a look — but it might just mean that squad finished early.

What compiling does

Merging happens on the tablet and always finishes. If online services are on, the app then:

  1. Publishes the shooter list, including any walk-ins the squads added.
  2. Uploads the match archive so the finished results are on the server.
  3. Checks for late uploads — a squad that arrived after you started compiling.
A failed upload never spoils a good compile. If the server can't be reached, the summary says what did and didn't happen, and the results are still on the tablet to view, print and email. A Try publishing again button picks up where it left off rather than starting over.

Corrections after compiling

Spotted a wrong division or a mistyped time? Go to the Roster, fix it, and compile again. The already-compiled squads stay unticked, so your correction stands and nothing is re-imported.

15 · Fixing a Mistake

The single best habit: collect every tablet before compiling anything. Almost every problem in this section comes from a score being corrected on one tablet after the match was compiled on another. Once the match is compiled, corrections belong on the compiling tablet, and squad tablets should stop uploading.

The app has a copy of this section built in — from the summary after compiling, tap How do I fix a mistake?

Before that squad has uploaded

The score only exists on that squad's tablet. Fix it there on the Roster, then upload as normal.

Uploaded, but the match isn't compiled yet

Fix it on that squad's tablet and upload again. Uploading twice is fine — whoever compiles picks up the newer copy automatically. "I already uploaded" is not a point of no return.

After the match has been compiled

  1. On the compiling tablet, go to the Roster and fix it.
  2. The results and the PDF update immediately — save a fresh PDF from Results & email.
  3. Tap Publish corrected results so the server matches.
Don't tick squads on the compile screen again. That re-imports the server's copy of the squad, which still has the old value — you'd end up with the shooter listed twice, once corrected and once not. Editing on the Roster is all that's needed.

A squad RO fixed it on their own tablet after you compiled

Their squad appears on the compile screen flagged re-uploaded since you compiled and is left unticked. Including it re-imports the whole squad, not just what changed, so anything you corrected on the compiling tablet would be duplicated. Make the change on the compiling tablet instead.

A shooter is in the wrong division

If they're listed under two divisions and one is wrong, open their score sheet and tap remove beside the wrong division on the "divisions this match" card. Their other divisions aren't affected.

To remove a shooter altogether, use Tools › View & edit shooter list.

Undo

Undo steps back to a moment in time, not just the one action. Anything scored since is lost too. Use it straight after a mistake or not at all.

16 · Backups, Undo & Recovery

Tools › Save a file… offers three things:

Match archiveThis match with all scores — your record of the night.
Shooter listNames only, no scores — the file other tablets restore.
Results spreadsheetOne row per score, as a CSV.

Restore from a backup file (under Careful) replaces everything on the tablet, scores included. Undo reverses the last few major changes — compiling, restoring, removing a shooter, or starting a new match.

Undo steps back to a moment in time. Anything scored after that point is lost too. Use it straight after a mistake, not later in the match.

If a tablet dies

Its last upload is on the server. On a replacement tablet, set the same match date and type, then Tools › Restore a squad from the server and pick that squad by name. The tablet takes over that squad and you can carry on scoring.

This is why uploading matters during the match, not just at the end. A tablet that uploaded at 8:40 can be recovered to 8:40. One that never uploaded can't be recovered at all.

17 · End-of-Match Workflow

Collect the tablets before compiling. It takes a minute and avoids nearly every problem in section 15 — corrections made on a squad tablet after the match was compiled elsewhere are the main source of duplicated shooters.
  1. Each RO taps Upload this squad's results (or saves the file and hands it over).
  2. One person taps Compile match results and selects every squad.
  3. Read the summary — squads compiled, anything flagged, and whether publishing succeeded.
  4. Produce the results: Save as PDF, emails, CSV.
  5. Spotted a mistake? See section 15 — fix it on the Roster and use Publish corrected results.
  6. Later, Start new match when you're finished with the results.
Offline it's the same shape, with files instead of uploads: each RO saves their file, the compiler adds them on the compile screen, and afterwards saves a shooter list file for the tablets to restore before the next match.
Fix duplicate shooters before publishing. If the same walk-in was added on two tablets, the merge summary flags it. Left in place, the duplicate is copied to every tablet with the next shooter list.

18 · Screen Modes

Tools › This Tablet › Screen offers three:

DefaultNormal indoor and shade conditions.
SunlightMaximum contrast for scoring in direct sun. Thin outlines and grey text are what disappear first in glare, so this removes them.
NightWarm and dimmed for a dark range, so the screen doesn't spoil your night vision or anyone else's.
The choice belongs to the tablet and is remembered. A tablet that lives in the sun stays in Sunlight mode.

19 · Scoring Rules Reference

Outdoor — time-plus, lowest total wins

Your score is your shooting time plus penalty seconds.

Penalties

ResultPenalty
Paper — A zone (center)+0 s
Paper — C ring+1 s
Paper — D zone+3 s
Paper — miss (off paper)+10 s
Steel popper left standing+10 s
Plate left standing+10 s

The three stages

StageStringsTargetsHits/target
Five to Glock35 paper6*
Glock'M34 paper + 1 steel popper per string6* paper
Glock the Plates46 steel platesall fall

* Major Sub / Pocket Glock divisions shoot 3 hits per paper target; the app detects this from the division name and adjusts automatically.

Stage score = string times + penalties. Match total = the three stages added together. Lowest total wins.

Indoor — score and X count, highest wins

ItemRange
Score0 – 500
X count0 – 50
Best possible500 · 50X

Highest score wins. X count breaks ties. Identical score and X share a place. Each round is ranked separately; a shooter may fire more than one round, each with its own division and Glock.

Divisions

Stock, Civilian, Competition, MOS, Unlimited, Major Sub, Pocket Glock, Subcompact, Heavy Metal, Rimfire, Guardian — the same list for indoor and outdoor.

20 · Troubleshooting & FAQ

"A stage won't confirm."

Something doesn't add up — a paper target, the steel, or a plates string. The message names which. See section 7.

"The app won't open with no internet."

It needs one successful online load first. Get on wifi, open it from the icon, let it finish loading.

"This tablet shows a different version to the others."

Fully close it and reopen while online, then check Tools again.

"There's a yellow badge at the top of the screen."

A squad was saved but not uploaded. Tap the badge to retry once you have signal.

"The compile screen is empty."

Check the match date and type match the squads you're expecting — that's how the app finds them. If squads sent files rather than uploading, use + Add squad files.

"A squad I already compiled is unticked."

That's deliberate — it's already in the results, and leaving it unticked protects any corrections you've made since. Tick it only if you genuinely want to re-import the server's copy.

"It says the shooter list published but the archive didn't."

The shooter list is safe. Tap Try publishing again — it resumes rather than starting over. The results are on the tablet either way and can be printed and emailed.

"Tapping a name or email box doesn't bring up the keyboard on my iPad."

An Apple bug affecting installed web apps generally. Restarting the iPad usually clears it. Scoring is unaffected — times, scores and X counts use the app's own number pad.

"My scores have disappeared."

Check whether the app was opened in the browser instead of from the home screen icon — those keep separate data. Otherwise restore the most recent backup.

"The same shooter is listed twice in the results."

Either they entered two divisions (correct — each is ranked separately), or they were added as a walk-in on two tablets. The merge summary tells you which. Remove the wrong one with Tools › View & edit shooter list.

"I corrected a score after compiling — how do the results get to the server?"

Tap Publish corrected results on the Results screen. It updates the shooter list and the match archive on the server. See section 15.

"A squad says re-uploaded since you compiled."

That squad's RO changed something on their tablet and uploaded again after you compiled. Don't tick it — including it re-imports the whole squad and duplicates anything you've corrected. Make the change on the compiling tablet instead.

"I published the wrong shooter list."

Tools › View & edit shooter list › Earlier versions, pick the good one, roll back.

"Did I lose scores when the screen locked?"

No. Everything auto-saves. Reopen the app and carry on.

Quick Cheat Sheet

Before the match: check every tablet shows the same version → Tools: set squad name, get the latest shooter list → Setup: pick Indoor/Outdoor and the match date → check shooters in → Start match.

Scoring outdoor: tap a shooter → tap a string box, enter the time → tap zones for hits → Confirm stage › Accept.

Scoring indoor: tap a shooter → enter Score and X → Confirm round › Lock → + Add another round if they're shooting again.

End of your squad: Results › Upload this squad's results.

Compiling (one person): Compile match results → tick every squad → read the summary → Save as PDF and email. Publishing happens automatically.
