Match Scorekeeper

User manual — scoring for GSSF-style indoor & outdoor matches

app v2.0.0

This app keeps score for a squad on one tablet, with no internet needed. Each tablet holds its own squad; at the end of the match the squads are combined on one device to produce the final results.

1 · How It Works

Match Scorekeeper runs entirely on the device. Nothing is uploaded, no account is needed, and no signal is required once it's installed.

  • One tablet = one squad. Each RO scores their own squad on their own device.
  • Everything saves as you go. Look for the ✓ saved time at the top right. Locking the screen or closing the app doesn't lose anything.
  • Indoor or outdoor. The match type is chosen at the start and stays fixed for that match.
  • Squads combine at the end. Each RO sends their file to one person, who merges them all and produces the results.
The shooter list is kept between matches. Starting a new match clears the scores and check-ins but keeps everyone's names, emails and details on file, ready for next time.

2 · Installing

There's no app store download. You open the address below once in a browser, then add it to the home screen. After that it has its own icon and works completely offline.

gpl-scorekeeper.netlify.app

iPad or iPhone

  1. Open the address in Safari. This must be Safari — Chrome on an iPad can't install apps.
  2. Tap Share (the square with an arrow pointing up).
  3. Scroll down and tap Add to Home Screen, then Add.
  4. Close Safari and open the new bullseye icon.
  5. While you still have internet, let it finish loading once.

Android tablet or phone

  1. Open the address in Chrome.
  2. Tap Install if offered, or menu ⋮ → Install app / Add to Home screen.
  3. Open it from the new icon and let it finish loading once while online.

Windows PC or Mac laptop

  • Simplest: open the address and bookmark it.
  • As an app window: in Edge or Chrome, click the install icon in the address bar. On a Mac in Safari, use File → Add to Dock.
  • Firefox can't install it as an app, but the website works normally.
First load needs internet — after that, none. Open it once on wifi so it can store itself on the device. From then on it opens and scores with no signal at all.
Always open it from the home screen icon, never from the browser. The icon version and the browser version keep separate saved data — score a squad in the browser by mistake and those scores won't be in the app. On iPads there's a second reason: the browser version can quietly discard its data after about a week unused, while the home screen version doesn't.

For the same reason, never use "Clear History" or "Clear browsing data" on a match tablet.

3 · Updating

Updates install themselves. Nothing to download, no app store to check.

  1. Fully close the app — don't just switch away. On a tablet, swipe it off the recent-apps list.
  2. Open it again while you have internet. The new version loads.
  3. Check Match Setup — it shows the version and build. Every tablet should show the same one.
Updates never install mid-match. If a new version is released while you're scoring, it waits until the next time the app is fully closed and reopened.

4 · Checking the Version

The version appears in two places: next to the app name in the header, and on the Match Setup screen along with the build.

Before every match, confirm all tablets show the same version and build. Mismatched tablets are the most common cause of odd behaviour when combining squads.

5 · Match Setup

Match Setup is the first screen you see. It's where the match is defined before any scoring begins.

  1. Match type — choose Outdoor or Indoor.
  2. Match (date) — the match name or date. This should be the same on every tablet; the app uses it to make sure squad files from different matches never get mixed together.
  3. Squad / relay on this tablet — e.g. Squad A. Appears in results and in the backup file name.
  4. Check in shooters — see section 6.
  5. Tap ▶ Start match.
The match type locks when you tap Start match. Indoor and outdoor score completely differently, so it can't be switched afterwards. Changing it means starting a new match.

After starting, the Roster, Score and Results tabs appear along the bottom. If you close and reopen the app mid-match, it returns straight to the match — you won't have to go through setup again.

6 · Shooters & Check-In

Tap Check in shooters (on Setup, or on the Roster once the match has started). The list shows everyone on file, one row per person, marked In or Out for tonight.

Tap a name to open their card and set:

  • Division and Glock model for tonight — these change week to week, so they're set at check-in rather than stored permanently.
  • Email — used for sending results afterwards.
  • RO — tick this and their email is always included in the results email, even if they didn't shoot.

Use + Add shooter (or + Walk-in during a match) for someone not on the list. Latecomers can be checked in at any point.

Shooting order is check-in order. The roster is numbered 1, 2, 3… in the order people were checked in.
Correcting a name or email fixes it everywhere. If a shooter is entered in more than one division, editing their details updates all of their entries at once. Division and Glock model stay separate for each one.

Shooting more than one division

A shooter can enter more than one division in the same match — for example Stock, then Unlimited, then Rimfire, each with its own Glock. Each one is scored and ranked separately. In the check-in list they still appear as a single person, showing how many entries they have.

7 · Scoring — Outdoor

From the Roster, tap a shooter to open their score sheet. The three stages are listed with a running match total at the top.

Entering times

Tap a String box and the number pad appears. Type the digits and the decimal fills in from the right — 1673 becomes 16.73. Tap Save.

On a laptop you can type the numbers directly on the keyboard, press Enter to save or Esc to cancel. The pad is used everywhere so scoring behaves identically on every device.

Entering hits

  • Tap a zone box (A, C, D, miss) to add one hit.
  • Long-press a box to reset it to zero.
  • The app refuses taps past the limit for that target and shakes the box.

Confirming a stage

Tap ✓ Confirm stage. The stage total is shown for you to Accept or Reject & edit. Accepting locks the stage — it turns green and the inputs grey out, so it can't be changed by accident. To reopen it, tap Review / edit then Unlock.

On the Roster, each shooter shows three dots — F, M, P — that turn green as each stage is confirmed, so you can see at a glance who still has stages outstanding.

Glock the Plates must account for all 6 plates on every string. Hits plus plates left standing has to total 6, or the app won't let you confirm the stage and will tell you which string is short. A plate left standing that isn't recorded would silently cost the shooter its 10-second penalty.

8 · Scoring — Indoor

Indoor matches are scored by score and X count, not by time. From the Roster, tap a shooter to open their rounds.

A round

Each round records:

  • Score — 0 to 500
  • X — 0 to 50

Tap either box to open the number pad, enter the number, tap Save. The app won't accept a score above 500 or an X count above 50.

Confirming a round

Tap ✓ Confirm round, check the score shown, and Lock it. A locked round greys out; tap Review / edit to reopen it. A round can't be locked with no score unless it's marked DNF or DQ.

Shooting more rounds

A shooter fires at least one round and may choose to shoot more. Each round can use a different Glock and division, but the gun stays the same within a round.

  1. Finish and confirm the current round.
  2. Tap + Add another round — it stays greyed out until the current round is confirmed.
  3. Choose the division and Glock for the new round.

Before a round is locked you can also tap change next to the division to correct the gun or division for that round.

Every round is ranked on its own. A shooter who fires three rounds appears three times in the results — once per round — and the results also show a per-shooter summary and their best round.

9 · DNF & DQ

On the score sheet, set Status to DNF (did not finish) or DQ (disqualified). Tap the same button again to clear it back to Finished.

  • Outdoor: the status applies to that shooter's entry.
  • Indoor: the status applies to that round, so a shooter can complete one round and DNF another.

DNF and DQ entries are listed at the bottom of the results rather than given a place, and they're excluded from best-score calculations.

10 · Reading Results

The Results tab ranks everyone. Filter chips at the top narrow the list by division and, if more than one squad is present, by squad. The match name is shown at the top with an edit link if it needs correcting.

Outdoor

Lowest total wins. Each row shows the shooter, division, Glock and their match total.

Indoor

Highest score wins; X count breaks ties. If two rounds have the same score and the same X count, they share a place. Results also include:

  • Best per division — the top round in each division.
  • Per shooter — one line per person listing all their rounds, with their best highlighted.

12 · Backups, Undo & Recovery

Backup

Results ▸ Backup saves a .json file to the device's Downloads folder. The Results screen shows when the last backup was taken.

Back up at the end of every squad, and before merging. It costs seconds and it's the one thing that survives a lost or broken tablet.

Restore

Results ▸ Restore replaces everything on the tablet with a backup file. Use this to load the shooter list onto a tablet before a match.

Undo

The app remembers the last three major changes — merging, restoring, and starting a new match. If something goes wrong, tap ↶ Undo on the Results screen (or on the merge summary). It tells you exactly what it will undo and asks to confirm.

Undo steps back to a moment in time. Anything scored after that point is lost too. Use it straight after a mistake, not later in the match.

13 · Combining Squads (Merge)

One person collects the squad files and merges them into a single set of results.

  1. Save all the squad files onto the compiling device.
  2. Results ▸ Merge squad files.
  3. Select all of them at once.
  4. Read the merge summary.

The summary reports how many shooters were added and updated, which squads they came from, and flags anything needing attention.

What the app protects you from

MessageMeaning
Already merged Those scores were identical to what the tablet already had, so nothing was duplicated. Merging the same file twice is safe.
Different match The file's match name doesn't match this one — it was skipped so old scores can't be written into this match. Fix the match name if the label is simply wrong.
Wrong match type An indoor file was offered to an outdoor match, or the reverse. Skipped.
Scored differently on two tablets The same shooter was scored on two devices with different results. Both were kept so nothing is lost — check them and delete the wrong one from the Roster.
Duplicate shooters The same name exists as two separate people — usually added as a walk-in on two tablets. Delete the wrong one from the Roster. (Keep both if they really are two different people with the same name.)
Fix duplicates before distributing the shooter list. A duplicate person left in place gets copied to every tablet with the next roster file and stays there.

14 · End-of-Match Workflow

Two backups are made at the end of a match, and they do different jobs. Mixing them up is how last week's scores end up in this week's results.

  1. Each RO taps 📤 Send squad results.
  2. One person merges them all (section 13).
  3. Produce the results — Save as PDF, emails, CSV.
  4. Backup → keep this file. It's the archive of the match, scores included.
  5. Start new match → clears scores and check-ins, keeps the shooter list.
  6. Backup again → this clean file is the shooter list to distribute.
  7. Before the next match, every tablet uses Restore on that clean file.
Distribute the file from step 6, not step 4. The step 4 file still contains scores. Use Restore (not Merge) so every tablet ends up with an identical list, and have one person do the compiling and distributing — if two people do it, the lists drift apart.

15 · Scoring Rules Reference

Outdoor — time-plus, lowest total wins

Your score is your shooting time plus penalty seconds.

Penalties

ResultPenalty
Paper — A zone (center)+0 s
Paper — C ring+1 s
Paper — D zone+3 s
Paper — miss (off paper)+10 s
Steel popper left standing+10 s
Plate left standing+10 s

The three stages

StageStringsTargetsHits/target
Five to Glock35 paper6*
Glock'M34 paper + 3 steel poppers6* paper
Glock the Plates46 steel platesall fall

* Major Sub / Pocket Glock divisions shoot 3 hits per paper target; the app detects this from the division name and adjusts automatically.

Stage score = string times + penalties. Match total = the three stages added together. Lowest total wins.

Indoor — score and X count, highest wins

ItemRange
Score0 – 500
X count0 – 50
Best possible500 · 50X

Highest score wins. X count breaks ties. Identical score and X share a place. Each round is ranked separately; a shooter may fire more than one round, each with its own division and Glock.

Divisions

Stock, Civilian, Competition, MOS, Unlimited, Major Sub, Pocket Glock, Subcompact, Heavy Metal, Rimfire, Guardian — the same list for indoor and outdoor.

16 · Troubleshooting & FAQ

"The app won't open with no internet."

It needs one successful online load first. Get on wifi, open it from the icon, let it finish loading.

"This tablet shows a different version to the others."

Fully close it and reopen while online, then check Match Setup again.

"There's no Add to Home Screen on my iPad."

You're in Chrome. Open the address in Safari instead.

"Tapping a name or email box doesn't bring up the keyboard on my iPad."

This is an Apple bug affecting installed web apps generally, not this app. Restarting the iPad usually clears it. Scoring is unaffected — times, scores and X counts use the app's own number pad.

"My scores have disappeared."

Check whether the app was opened in the browser instead of from the home screen icon — those keep separate data. Otherwise restore the most recent backup.

"I can't change a division or gun I picked."

They're dropdowns — tap the field and choose again. For an unusual gun pick Other… and type it. For an indoor round that's already locked, tap Review / edit first.

"Merge says a file was skipped."

See the table in section 13 — it's usually a file from a different match or the wrong match type.

"The same shooter is listed twice in the results."

Either they entered two divisions (correct — each is ranked separately), or they were added as a walk-in on two tablets. The merge summary tells you which. Delete the wrong entry from the Roster.

"I merged the wrong file."

Tap ↶ Undo on the Results screen straight away.

"A shooter dropped out or was disqualified."

Open their score sheet and set Status to DNF or DQ.

"Did I lose scores when the screen locked?"

No. Everything auto-saves. Reopen the app and carry on.

Quick Cheat Sheet

Before the match: confirm the version matches the other tablets → Match Setup: pick Indoor/Outdoor, set the match date and squad → check in shooters in shooting order → Start match.

Scoring outdoor: tap a shooter → tap a string box, enter the time on the pad → tap zones for hits (long-press to reset) → Confirm stage ▸ Accept → next shooter.

Scoring indoor: tap a shooter → tap Score and X, enter on the pad → Confirm round ▸ Lock → + Add another round if they're shooting again.

End of your squad: Results ▸ 📤 Send squad results → also Backup for safety.

Compiling (one person): collect all squad files → Results ▸ Merge squad files → select all → read the summary → Save as PDF and email → Backup (archive) → Start new match → Backup again (shooter list to distribute).
