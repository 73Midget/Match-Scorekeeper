Merge Squad Results — Step by Step

What this does: Combines all squad backup files from tonight into one master list with all scores and shooters. You only do this once, on one tablet, at the end of the match.

BEFORE YOU START — Each Squad Must Backup

On every scorekeeper's tablet (Squad A, B, C, etc.):

  1. Open the Results tab
  2. Tap Backup (orange button)
  3. A file like match-backup-SquadA-….json downloads to your Downloads folder
  4. If using shared Google Drive: Open the Google Drive app, tap + to upload, select that backup file, and save it to the shared RO folder
NOW MERGE — On This Tablet Only
  1. Get all backup files. If they're on Google Drive, open the Google Drive app, find each squad's backup file, and download them to this tablet's Downloads folder. (Or ask each squad RO to email/text you their backup file and save it to Downloads.)
  2. Stay on this screen. You're ready to merge.
  3. Tap "Choose files" below.
  4. Select EVERY squad's backup file at once. When the file picker opens, tap or click each backup file. On a tablet, tap one, then tap the others while holding. On a computer, hold Ctrl/Cmd and click each file. Make sure you see all files highlighted before tapping "Open" or "Done".
  5. Wait for merge to finish. A message will appear showing how many shooters were added, updated, and if there are any conflicts.
  6. Read the summary carefully. Look for:
    • Added: new shooters from other squads ✓ good
    • Updated: shooters already on this tablet who got scores from other squad files
    • Conflicts: same person scored on two different tablets. App kept both; check Roster and delete the duplicate.
  7. If conflicts flagged: Go back to the Roster tab and look for duplicate names. Keep the entry with scores, delete the empty one.
AFTER MERGE — Verify & Share Results
  1. Go to the Results tab. You should see shooters from all squads ranked together.
  2. Scroll through and spot-check: Are all squads represented? Are the rankings correct?
  3. Share results: Tap 📊 Squad results & email to email scorecards, download the HTML sheet, or copy a formatted table.
  4. Final backup: Tap Backup one more time so you have a complete record of everything merged.
Important notes:
• Each squad RO taps Backup on their own tablet first — not you
• You only tap "Choose files" and select all of them at once
• Never use "Restore" unless recovering from a failed backup — it erases your current data
• "Merge" only adds; it never erases scores already on this tablet
• If someone new checked in late on another squad, they'll automatically appear here
